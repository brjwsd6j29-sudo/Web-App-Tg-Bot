⚔️ Как работает jCoin PvP
Каждый раунд длится 20 секунд.

В период подготовки игроки выбирают количество виртуальных очков участия.

Чем больше значение, тем больше визуальная зона игрока на арене.

После завершения подготовки шарик перемещается по арене и выбирает одну из зон для определения результата.

В этой демоверсии результат используется только для XP, статистики и рейтинга. jCoin не являются реальными деньгами.
